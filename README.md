# capstone-research

UChicago MS ADS capstone thesis. Legal LLM reasoning. Showcase Aug 15, 2026.

## Folders

- `paper/` — paper drafts
- `notebooks/` — jupyter notebooks
  - `legal-rag/` — main paper experiment (SaulLM + retrieval on CaseHOLD)
  - `saul-7b/` — SaulLM chat + failure probes
  - `concept-lm-staged-notebooks/` — earlier concept-lm work
- `code/` — standalone python scripts
- `data/` — small tracked datasets
- `outputs/` — figures, tables, results
- `references/` — cited papers and external repos (local only)
- `notes/` — research notes and lit review
- `team/` — meeting notes, decks, admin
- `docs/` — design notes, decisions
